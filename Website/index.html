What it does

A desktop companion with a body, a brain, and a toolbox

TypePet is more than an animation. It reads your desktop, holds a conversation, runs commands you can write yourself, and exposes itself as a tool any AI agent can drive.

Walks your windows

It builds a live platform-and-ladder map from the windows you have open — top and bottom edges, clipped to what's actually visible — and roams it in real time as you move things around.

REAL-TIME GEOMETRY

Talks back with AI

Pop the say bar with a hotkey and chat. Replies are spoken in a bubble and shown in history. Bring your own key for Claude or any OpenAI-compatible model — it stays on your machine.

CLAUDE · OPENAI

Searches & remembers

Ask about the weather, news or prices and it searches the web for you. Tell it to remind you about something and it schedules it — naturally, in your own words.

WEB · REMINDERS

Slash commands

Type / to run a command. Each one is a plain command.md file — text, image, clipboard, an LLM prompt, a pet action, or a sandboxed script. Edit and it hot-reloads.

NO BUILD · HOT-RELOAD

A community hub

Browse and install commands others have published, straight from a GitHub-backed registry. Every download is SHA-256 verified, with an up-front disclosure of what it can touch.

VERIFIED INSTALLS

Dress-up & characters

Pick from a character library, import or export them as zips, and live-swap on the fly. Each character is a sprite of body, head and equipped items with its own poses.

IMPORT · EXPORT · SWAP

Drive it over MCP

TypePet hosts a local Model Context Protocol server. Any MCP-capable agent can list the pet's abilities and make it move, act and emote — your screen becomes a tool the AI can use.

LOCAL MCP SERVER

Native & permission-free

One codebase, two native heads — Win32 on Windows, CoreGraphics & AppKit on macOS. The whole macOS feature set runs with zero accessibility or screen-recording permissions.

.NET 10 · AVALONIA
The core trick

Your windows are the level

There's no fixed map. TypePet looks at the windows on your screen and turns their edges into a platformer stage — then plans a route across it and walks the route.

1
Read the desktopEvery visible window's top and bottom edge becomes a walkable platform, clipped against whatever sits in front of it.
2
Plan a pathThe visible platforms and side edges form a navigation graph. The pet picks a reachable spot and plans how to get there.
3
Walk, jump & climbShort gaps get a parabolic hop; taller ones a ladder climb up a window's side; it down-jumps through to the platform below.
4
Adapt & recoverMove a window and it replans. If the surface under its feet vanishes, it falls — and finds its footing again.
green = platforms · orange = ladders

Slash commands

Teach it new tricks in a text file

A command is just a folder with a command.md inside. Frontmatter on top, the body below. No build step, no restart — save the file and the command appears. Click one to try it:

/wave
👋 *waves at you*

Kinds: text, clipboard, image, link, prompt (runs through the LLM), pet (plays an action), and sandboxed script.

cmd_hello/command.md
---
name: hello
kind: text
usage: /hello [name]
help: Greet a friend.
---
Hi there, {{args}}! Welcome ✨

Open the say bar, type /hello Steve, and your pet says “Hi there, Steve! Welcome ✨” — the moment you save the file.

Get TypePet

Run it in a couple of minutes

TypePet builds from source with the .NET 10 SDK, or grab a prebuilt artifact from GitHub. Pick your platform:

Terminal — macOS 13+ (Apple Silicon or Intel)
# build a double-clickable, ad-hoc-signed app — no Apple account needed
$ git clone https://github.com/Leonana69/MaplePet.git
$ cd MaplePet
$ ./packaging/macos/build-macos-bundle.sh
$ open artifacts/TypePet.app

Prefer to just run it? dotnet run --project TypePet.csproj -f net10.0. The whole macOS feature set needs no accessibility or screen-recording permissions.

PowerShell — Windows 10/11 (x64)
PS> git clone https://github.com/Leonana69/MaplePet.git
PS> cd MaplePet
PS> dotnet run --project TypePet.csproj -f net10.0-windows

You'll see your windows outlined and the pet roaming them. Quit from the tray icon's Exit. Turn on “Start with Windows” in Settings to launch it at login.

Any platform — needs the .NET 10 SDK
# the project multi-targets net10.0-windows and net10.0 (the macOS head)
$ git clone https://github.com/Leonana69/MaplePet.git
$ cd MaplePet
# pick the head for your OS with -f:
$ dotnet run --project TypePet.csproj -f net10.0          # macOS
$ dotnet run --project TypePet.csproj -f net10.0-windows  # Windows

CI builds both heads on their native runners and uploads the Windows executable and the macOS .app bundle — grab the latest from the repo's Releases or Actions artifacts.

Good to know

Questions, answered

Is it really free?

Yes. TypePet is free and open-source software under the GNU General Public License v3. You can read, modify and redistribute the source. AI chat uses your own API key, so any model usage is billed by your provider — not by TypePet.

Does it need scary permissions?

No. On macOS the entire feature set — window tracking, the overlay, the grab, the hotkey — runs without any TCC permissions (no accessibility or screen-recording prompts). On Windows it reads window geometry through standard Win32 APIs.

Where do my API keys and chats go?

They stay on your machine. You configure an Anthropic or OpenAI-compatible endpoint in settings; messages go directly to the model you chose and nowhere else. There's no TypePet account and no telemetry server.

Will it get in the way of my work?

The overlay is click-through, so everything behind the pet stays fully usable — you can still grab the pet itself with the mouse. It also tucks away automatically while a borderless or exclusive-fullscreen app (a game or video) is in front, and comes back when you alt-tab to the desktop.

Are community commands safe to install?

Each hub download is verified against a SHA-256 checksum before it's extracted, and you see an up-front disclosure of what a command needs — scripting, network access and which hosts — before installing. Scripts run in a sandbox and network access stays off until you approve it.

What are the sprites — is this a MapleStory thing?

The default character is rendered from MapleStory-style sprite footage, and the chat's game knowledge base is tuned for MapleStory questions. TypePet is an independent, fan-made project and is not affiliated with or endorsed by Nexon or MapleStory. You can swap in your own characters at any time.
